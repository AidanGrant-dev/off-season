# Off-Season Plan

A week-by-week off-season training plan app: 13 weeks of speed, strength, aerobic and RSA
programming across Block 0 (Regeneration), Block 1 (General Preparation) and Block 2
(Speed & Power), plus a reference view for Block 3 (Conversion / Pre-season).

- **Week-by-Week** — the full daily schedule with progress tracking (persisted to
  `localStorage`), auto-highlighting the current week/day.
- **Overview** — the reframe, the January half-marathon decision point, timeline and
  sequencing rules.
- **Strength** — the gym program periodised across blocks.
- **Aerobic & RSA** — VO₂ session design, RSA/special-endurance timeline, off-feet
  conditioning guidance.
- **Testing** — benchmark definitions plus a form to log test results over time.
- **Monitoring** — ACWR/HRV/CMJ decision rules and injury-prevention notes.
